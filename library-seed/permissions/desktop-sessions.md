# permission: desktop-sessions — work on this routine's own desktop

The desktop is this routine's own computer; its home folder carries over between runs. The
operator can watch and take it over: when the screen changed without an action of yours, wait
and look again — never undo it.
Point at things by NAME before pixels: act on a numbered element from the screen's list; read
coordinates off a screenshot only for what has no name, and check a close-up before clicking.
Look at what each action did before the next one.
Bring files in by mounting a granted folder, read-only unless desktop apps must write it.
Its browser is signed into nothing of the operator's: never type a password, login code or
payment detail, nor ask for one. A login or purchase wall is the operator's to pass on the
screen — ask once in a deferred question, then carry on with what needs neither.
When every desktop is taken, do the work that needs no screen.
